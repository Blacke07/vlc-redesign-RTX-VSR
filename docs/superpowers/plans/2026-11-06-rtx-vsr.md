# RTX VSR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Expose the tested RTX VSR configuration as one persistent Performance switch.

**Architecture:** A derived ConfigModel row stages existing VLC settings and uses
the existing transaction to save them. A small Qt Core helper owns the preset
and filter-list rules so they can be tested without compiling the VLC engine.
Post-processing shares the staged video-filter value with the new row.

**Tech Stack:** Existing Qt 6/QML, C++17, GitHub Actions, Windows x64 build scripts.

**Spec:** ../specs/2026-11-06-rtx-vsr-design.md

## Global Constraints

- Base: v0.5.3; branch: feat/rtx-vsr-toggle; repository: Blacke07/vlc-redesign.
- ON: vout=direct3d11, dec-dev=d3d11_filters, d3d11-upscale-mode=super, no postproc.
- OFF changes only d3d11-upscale-mode to linear. Preserve unrelated filters.
- Reuse Save/Cancel and the restart indicator; do not add a persisted boolean.
- Keep installed VLC and unrelated settings unchanged. No new library dependencies.

## Review Focus

- A manually changed decoder/output/filter must update the derived switch.
- An absent Direct3D11 plugin must leave the control absent.
- Staged post-processing and VSR changes must not overwrite each other on Save.
- Cancel and failed saves must preserve the configuration on disk.
- A portable test copy must not import or overwrite the installed player's profile.
